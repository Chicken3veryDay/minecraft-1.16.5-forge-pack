Crazy Craft 4.0 QoL mod drop folder
===================================

Put optional legacy Forge 1.7.10 QoL jars here when the installer cannot fetch them automatically.

Folders:

- both\   install to both client and server
- client\ install to client only
- server\ install to server only

Recommended jars:

both:
- VeinMiner for Minecraft 1.7.10
- FastLeafDecay for Minecraft 1.7.10

client:
- Mouse Tweaks for Minecraft 1.7.10
- TrashSlot for Minecraft 1.7.10, if using a confirmed 1.7.10 build
- BetterFps for Minecraft 1.7.10, optional and should be tested because FastCraft is already present

server:
- Morpheus for Minecraft 1.7.10
- AromaBackup for Minecraft 1.7.10
- Aroma1997Core for Minecraft 1.7.10 if AromaBackup requires it
- Stackie for Minecraft 1.7.10, optional and should be tested

VeinMiner config policy:
- Allow ores and logs only.
- Keep stone, dirt, sand, gravel, netherrack, and end stone disabled.
- Require a tool and sneak/keybind.
- Keep max blocks around 32-64 for the small VPS.
